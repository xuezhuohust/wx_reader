# Frontend Design Skill

此技能专注于微信小程序的前端界面设计、用户体验优化以及样式编写。

## 核心职责

1. **UI 设计与美化**: 为小程序页面提供现代、简洁且美观的视觉设计。
2. **WXSS/WXML 编写**: 编写高质量、可维护的样式代码和页面结构。
3. **UX 优化**: 改进交互流程，提升用户操作的流畅度和直观性。
4. **响应式布局**: 确保在不同尺寸的手机屏幕上都能完美展示（利用 rpx、flex 布局等）。
5. **组件化**: 设计和实现可复用的自定义组件。

## 触发场景

- 当用户要求“让界面更好看”或“美化页面”时。
- 当需要创建新的页面或组件并设计其样式时。
- 当现有的布局在某些设备上显示不正常时。
- 当需要优化交互反馈（如点击态、加载态）时。

## 遵循原则

- **微信小程序规范**: 遵循微信官方设计指南。
- **一致性**: 保持全局颜色、字体和间距的一致性。
- **性能**: 避免过度复杂的 CSS 选择器和冗余的节点。
- **易用性**: 确保关键操作按钮易于点击，信息层级清晰。

## 常用工具与模式

- **Flex 布局**: 首选的布局方式。
- **rpx 单位**: 用于实现屏幕自适应。
- **WeUI**: 适时参考或使用微信官方基础组件库。
- **自定义组件**: 将通用的 UI 元素封装为组件。
